# 01 — Overview

## What is SpendWise?

SpendWise is a web application for tracking income and expenses, managing monthly budgets, and receiving real-time spending notifications.

## How It Works

1. The user creates an account or signs in.
2. The user sets monthly budgets for different categories, such as €200 for groceries.
3. When adding an income or expense, the user selects a category and enters the amount.
4. The transaction is saved, and the relevant spending total is updated.
5. If spending reaches 80% or 100% of a budget, the user receives a notification without refreshing the page.
6. The dashboard displays transactions, budgets, and spending totals.

## Main Features

- User registration and login
- Add, view, update, and delete transactions
- Organize income and expenses into categories
- Create and view monthly budgets
- Track spending against budget limits
- Receive real-time budget notifications
- View transactions and budget summaries on a dashboard
